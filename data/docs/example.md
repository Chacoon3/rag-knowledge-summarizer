# 本地 RAG 示例文档

这个示例项目实现了一个完全本地运行的知识库系统。

## 入库流程

1. 把知识文档放到 `data/docs/`。
2. 执行 `python main.py ingest`。
3. 系统会读取文档、切片、生成 embedding，并把索引持久化到 `storage/`。

## 查询流程

1. 执行 `python main.py query "你的问题"`。
2. 系统会先从本地索引中召回最相关片段。
3. 如果检测到 Ollama 可用，会基于检索结果生成自然语言答案。
4. 如果 Ollama 不可用，则返回相关片段摘要。

## 支持的格式

系统支持 `.txt`、`.md`、`.pdf`、`.docx` 四类文档。
